## AGENTS.md 문서 지도 추가안 — 미적용

기존 4장 표에 다음 행을 추가하는 안입니다. 이번 세션은 `AGENTS.md`를 수정하지 않습니다.

| 바꾸는 경로 | 먼저 읽을 문서 |
|---|---|
| `src/`의 코드 구조·상태·폼·타입·오류 처리·테스트 리팩터링 | `docs/conventions/clean-code.md`의 관련 CC 항목 + 기존 문서 지도에서 해당 경로의 문서 |

하네스 수정이므로 사용자가 변경안을 승인하고 허용된 세션에서 적용해야 합니다. 문서 지도 추가 전에도 C2 지시문은 이 파일을 명시적으로 읽도록 합니다.
